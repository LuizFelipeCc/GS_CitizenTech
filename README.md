# Nome da CitizenTech: SPMelhor

### Cidade e Bairro: 
- Cidade: São Paulo ; Bairro: Jaguaré

### Cidadão Beneficiado: 
- Moradores que circulam pelas ruas de Jaguaré

### Problema em uma frase: 
- Insatisfação dos moradores do bairro com a falta de agilidade e controle na resolução de problemas de infraestrutura urbana.

### Como Funciona: 
- Um sistema onde o cidadão pode registrar os problemas informando o local e a descrição do problema.

###  O que cada parte faz: 
- Ajuda no contato do morador com a prefeitura
